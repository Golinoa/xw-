### 根因（探针拿到的证据，不是猜的）
1. `apps/web-antd` 下**同时存在 `vite.config.ts` 与 `vite.config.mts`**。
   Vite 8 实际加载的是 `.ts`（原版、无契约别名），我上午把别名写进了 `.mts`
   ⇒ dev 报 `Failed to resolve import "@erp/contracts"`；build 却正常，掩盖了问题。
   **修法**：别名合并进 `vite.config.ts`，删除 `.mts`。提交 `a7cc898`。
2. `optimizeDeps` 按项目根把 `zod` 预构建成顶层 **zod 3.25.76**，
   而 contracts 用 zod 4 顶层 API ⇒ dev 报 `z.email is not a function`。
   **修法**：`optimizeDeps.exclude: ['zod']`（Vben 自己的 zod 3 不受影响）。
3. 补建 `admin-clean/node_modules/@erp/contracts` junction → `udone/packages/contracts`
   （package.json 声明了 link 但一直没实体，node_modules 内不入库）。
