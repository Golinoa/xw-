# 安全约束

- 每个受保护 API 操作都验证身份、有效运营成员状态、权限和目标对象；禁止依赖 UI 显隐。
- 匿名、普通 `udone` 租户用户和被禁用运营用户访问运营 API 必须拒绝；RLS 对 `ops` 数据执行第二层隔离。
- 运营角色只授予处理其职责所需数据；客户联系方式、金额、合同附件、收款凭证、授权和导出分别按最小权限授权。
- 不公开注册运营账号；账号邀请、撤权和重置需审计；可信授权来自服务端成员关系/可信 token 声明，不能取自可编辑 user metadata。
- 凭证存入 Cloudflare Worker secrets/安全配置；不提交 `.env`、token、cookie、签名密钥或真实生产证据。
- 上传下载校验文件大小、MIME/扩展名、业务对象关系和请求权限；使用私有对象、不可猜测键和短期受限访问地址。
- 不保存私有化环境远程登录凭据；日志和审计 payload 脱敏，不记完整认证头、完整财务文件或无关个人信息。
- 身份、金额、退款、权益和租户状态写操作都记录 actor、时间、对象、原因和关联 request ID。
- 新个人/财务信息流程明确用途、访问角色、导出审计、保留和删除规则；测试只用虚构数据。
