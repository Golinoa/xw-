# 代码编写约束

适用范围：TypeScript、Vue、API 契约及与运营后台相关的 SQL（SQL 迁移实际位于 `udone`）。

## 类型和分层

- TypeScript 使用严格类型；外部 JSON、查询参数、环境配置和 provider 返回值按 `unknown` 验证。
- 避免 `any`、非空断言、双重类型断言和无边界 `@ts-ignore`；通过验证、窄化和适配器表达实际不确定性。
- 页面负责视图与流程组合；领域规则位于后端服务；数据库访问由后端数据层/事务接口管理。
- 文件命名和已有 Vben workspace 规范保持一致；跨项目只使用公开 API 契约。

## 禁止的捷径

- 不散落编码业务含义、单位、金额精度、权限、超时、分页、阈值、重试次数或状态编号的魔法数字/字符串。使用有意义的常量、枚举、配置或共享契约；普通算术 `0`/`1`、局部索引及一次性样式值无需抽取。
- 不吞异常、空 `catch`、返回成功形状的默认值或未跟踪的 fire-and-forget 任务；仅在调用方可恢复、翻译错误或执行回滚时捕获。
- 不用 truthiness 混淆 `0`、`false`、空字符串、`null` 与缺省值；不静默转换金额、日期、ID 和状态。
- 不信任前端隐藏按钮作为授权，不将未验证字符串拼入 SQL，不渲染不可信 HTML。
- 金额使用精确十进制；日期时间须明确时区与本地日期语义。
- API 字段名、权限名、状态和错误码由契约定义，不在界面和服务间重复造值。
- TODO 必须绑定明确负责人/计划；不得用 TODO 留下尚未决定的核心行为。

## 错误、注释和审查

- 面向用户返回稳定、安全、可操作的错误；内部诊断使用 request ID，不返回 SQL、堆栈、密钥或原始 provider 响应。
- 注释解释不明显的不变量、兼容边界和安全决策，不复述代码。
- 变更审查检查模块边界、输入验证、权限、失败恢复、敏感数据、空/错误/无权限状态和共享设计规范。
