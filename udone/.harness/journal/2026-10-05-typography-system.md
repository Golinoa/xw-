# 字体与排版规范

## 今日完成

- 从字体规范参考页提取 PingFang、12–24px 字号（每 2px 一级）及 Regular、Medium、Semibold 三档字重。
- 补齐字体回退、字号用途、行高、数字对齐、长文本截断和窄屏可读性规则。
- 新增规范与 HTML 预览，并更新 Design-system 索引。

## 关键决策

- 正文默认 14px / 22px；重要业务文字至少 14px；12px 仅用于辅助或密集内容。
- 中文首选 PingFang SC；回退到 Microsoft YaHei 和系统 UI 字体，不分发字体文件。
- 字号用途、行高和跨平台回退采用项目规则补齐，与参考页明确值分开说明。

## 遇到的问题

- 参考页未指定字号用途和行高；结合高密度管理后台确定默认映射。
