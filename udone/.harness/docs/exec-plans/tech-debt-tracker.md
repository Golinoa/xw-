# 技术债跟踪

当前未完成项统一维护于 [唯一复刻规格](../../../Docs/REPLICATION_SPEC.md) 的缺口章节及 [平台基础实施计划](../../../Docs/superpowers/plans/2026-10-02-platform-foundation.md) 的未勾选任务。

业务端（`udone`）的未完成项按执行粒度收敛于 [业务端未完成任务开发计划](../../../Docs/superpowers/plans/2026-10-29-business-completion-backlog.md)，含现状证据与验收标准；关闭其中任务时同步该文件与当日 journal。

仅在任务仍未记录于上述来源时，才在此增加独立技术债；关闭时附上验证证据。
