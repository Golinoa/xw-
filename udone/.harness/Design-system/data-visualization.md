# 有单 OMS 图表与数据可视化规范

> 状态：已定稿　|　适用范围：有单 OMS Web 管理后台　|　生效日期：2026-10-05

## 快速规则

- 图表服务于比较、趋势、构成或进度判断；选择最容易读懂的图表，不以装饰效果代替数据。
- 参考界面出现环形任务统计、纵向柱状对比和雷达能力分布；这些作为适用图表的优先样式。
- 图表按系列分配稳定颜色，并配标题、单位、图例或直接标签；不得仅靠颜色区分数据。
- 无数据、加载失败和数据过期均须有明确状态；不能显示为零值或空白图形。

## 1. 图表选择

| 目的 | 优先图表 | 使用规则 |
|---|---|---|
| 单项完成比例 | 环形进度图 | 中心显示数值或总量；比例与分子/分母一致 |
| 类别数量对比 | 柱状图 | 类别少且名称短时优先；坐标从零开始 |
| 多维度能力对比 | 雷达图 | 维度数量适中、量纲可比较；配维度标签和数据点 |
| 时间变化 | 折线图 | 时间等距，展示连续变化；说明统计周期和缺失值 |
| 部分占整体 | 堆叠条形或环形图 | 类别有限且总和明确；类别过多时改用表格 |
| 精确数值查询 | 表格或指标卡 | 需要逐项读取、排序或操作时不使用纯图形替代表格 |

- 不使用 3D、透视、面积阴影或不必要的动画制造视觉权重。
- 饼图和环形图类别建议不超过 5 项；更多类别合并为“其他”或改用表格。
- 雷达图不用于精确比较相近数值；维度过多或量纲不可比时改用条形图/表格。
- 同一视图只组合相关指标，避免多种图形争夺注意力。

## 2. 颜色与系列

- 状态类数据使用色彩规范中的成功、警告、错误、处理中等语意色。
- 普通类别序列使用蓝、青、绿、橙、紫等可区分色；不得让类别色暗示状态含义。系列顺序在同一报表和跨页面保持稳定。
- 单系列优先使用品牌蓝；次系列使用协同青或中性色。语意色保留给真实状态。
- 浅色画布上的线条、点和面积边界保持可辨；相邻系列避免只靠相近明度区分。
- 图形可使用浅色填充，但文字、刻度和关键数据标记使用满足对比度的颜色。

## 3. 标题、坐标与标签

- 图表标题说明指标和对象；时间图表标明统计周期，金额、数量和百分比明确单位。
- 坐标轴刻度数量保持适中，文字不重叠；数值格式统一，日期粒度与查询区间匹配。
- 柱状图的数值从零开始；如确需截断，必须明显标出截断范围并避免误导相对差异。
- 折线图缺失数据不得静默补零；说明断点或按业务约定显示缺失状态。
- 直接标签优先用于少量系列；多系列提供图例，并保证图例顺序与绘图顺序一致。
- Hover 提示用于补充精确值，核心结论必须在静态图表、图例或相邻摘要中可读。

## 4. 交互和数据状态

- 图表筛选变化时显示正在更新状态；防止旧数据被误认为新筛选结果。
- 点击图表进入明细时应有明确可操作提示；纯展示图不显示可点击光标。
- 空数据展示原因和可执行下一步；请求失败提供重试入口；权限不足说明访问限制。
- 数据更新时间、统计范围或口径影响结论时应可查看。
- 图表不替代可访问的文本摘要或表格数据；关键数值应可通过键盘或等价文本读取。

## 5. 响应式与性能

- 窄屏优先保留标题、当前值、图例和关键类别；减少装饰轴线，避免缩小到不可读。
- 图表在狭窄容器下可切换为横向滚动、精简类别或表格摘要；不要把标签压成重叠文字。
- 容器尺寸变化后重新计算绘图区；隐藏或折叠容器重新显示时也要恢复布局。
- 长时间序列按视图范围聚合或分页；避免一次绘制大量无关点。
- 配色与图表形态同时满足色彩、字体、组件和响应式规范。
