# 有单 OMS 字体与排版规范

> 状态：已定稿　|　适用范围：有单 OMS Web 管理后台　|　生效日期：2026-10-05

## 快速规则

- 中文首选系统字体 PingFang SC；按平台使用 Microsoft YaHei、系统 UI 字体回退。
- 使用 12、14、16、18、20、22、24px 七级字号，字重采用 400、500、600。
- 正文默认 14px / 22px；紧凑表格和辅助信息可用 12px / 20px。
- 主要层级由字号、字重和颜色共同表达；不能只靠颜色或字重传递含义。

## 1. 字体与字重

### 字体栈

```css
font-family: "PingFang SC", "Microsoft YaHei", system-ui, -apple-system,
  "Segoe UI", sans-serif;
```

使用系统已安装字体，不随产品分发字体文件。缺少 PingFang SC 时由浏览器使用后续回退字体。

### 字重

| Token | CSS 值 | 使用方式 |
|---|---:|---|
| Regular | 400 | 正文、说明、表格内容 |
| Medium | 500 | 导航、表头、字段标签、次级标题 |
| Semibold | 600 | 页面标题、区块标题、关键数字 |

不使用 700 作为常规界面字重；如组件库有独立字重定义，通过主题统一映射到以上三级。

## 2. 字号与行高

| Token | 字号 / 行高 | 默认用途 |
|---|---:|---|
| `text-xs` | 12 / 20px | 辅助说明、时间、密集表格 |
| `text-sm` | 14 / 22px | 正文、表单、导航、表格默认值 |
| `text-md` | 16 / 24px | 强调正文、列表主信息 |
| `text-lg` | 18 / 28px | 卡片标题、次级区块标题 |
| `text-xl` | 20 / 28px | 区块标题 |
| `text-2xl` | 22 / 32px | 页面次标题、重要摘要 |
| `text-3xl` | 24 / 32px | 页面标题 |

字号和行高按 CSS px 实现。正文默认 14 / 22px；用户输入和主要业务数据不得低于 14px。12px 仅用于非关键辅助信息或密集数据，避免连续长段落使用。

## 3. 使用规则

- 页面标题使用 24px / 600；区块标题使用 18–20px / 600；正文默认 14px / 400。
- 表单标签、导航和表头使用 14px / 500；表格内容使用 14px / 400，密集模式可降至 12px / 400。
- 关键数字可用 20–24px / 600；同一组数据保持字号、字重和基线一致。
- 字体颜色遵循 [色彩规范](color-system.md)。不要用低对比灰色承载关键内容。
- 中文界面默认不添加字间距；英文标题可以按实际视觉需要调整，不将展示页的装饰字距带入业务界面。
- 数字列按需使用 `font-variant-numeric: tabular-nums`，便于金额、日期和统计数据对齐。

## 4. 内容与可读性

- 文本容器应允许换行；长标题可折行，不通过缩小字号适配固定宽度。
- 表格单元格或紧凑导航需要截断时，界面必须提供可访问的完整内容查看方式，不能只依赖 hover 提示。
- 状态和层级还应使用文案、位置或图标，不单靠粗体或颜色区分。
- 页面缩放与窄屏下保持文本可读、布局可操作；文本放大不得被固定高度裁切。
- 使用语义化标题层级，标题字号可复用但不能跳过结构层级。

## 5. 规则边界

参考字体页直接给出 PingFang、12–24px 字号范围和 Regular / Medium / Semibold 字重。字号用途、行高、回退字体、数字对齐和截断行为由本规范补齐。组件如需偏离默认值，需在组件规范中说明适用场景；页面不得散落新增字体、字号或字重。

配套预览：[字体与排版 HTML](typography-preview.html)。组件库主题适配遵循本文件的字号和字重映射。

图标尺寸对应的文本基线和图表标签可读性，还须遵循[图标规范](iconography.md)及[图表与数据可视化规范](data-visualization.md)。
