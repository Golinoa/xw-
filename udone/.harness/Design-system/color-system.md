# 有单 OMS 色彩规范

> 状态：已确认生效　|　适用范围：有单 OMS Web 管理后台　|　确认日期：2026-10-05
>
> 快速规则：品牌蓝 `#0093FF`、品牌青 `#00D1C3`；浅色 UI 文字要配深色文字 token；白字实心按钮使用深色操作背景。

## 1. 色彩方向

本规范根据用户提供的项目管理产品视觉参考图制定。参考图的色彩规范页明确标出蓝色 `#0093FF` 为主色、青色 `#00D1C3` 为辅色；浅冷色画布、白色卡片、黑色文字构成基础视觉。参考作品中绿色、橙色、红色的 HEX 标注疑似重复占位，因此语意色按画面观感重新定义，并作为本产品的正式 token 使用。

## 2. 品牌色阶

| 阶 | 项目蓝 | 协同青 | 用途 |
|---|---|---|---|
| 50 | `#EAF6FF` | `#E6FBF9` | 极浅状态底、选区底 |
| 100 | `#CCEAFF` | `#C2F5EF` | 浅底、弱强调 |
| 200 | `#99D5FF` | `#8CEBE1` | 柔和图形、浅边界 |
| 300 | `#66C0FF` | `#55E1D3` | 图表或装饰 |
| 400 | `#33AAFF` | `#22D8C8` | 较强装饰强调 |
| 500 | `#0093FF` | `#00D1C3` | 品牌标准色；青色用于辅助强调 |
| 600 | `#0077D6` | `#00A99D` | 蓝色实心主按钮、主要数据图形 |
| 700 | `#005EAA` | `#00877E` | 链接、图表序列、悬停 |
| 800 | `#00477F` | `#00655E` | 按下态、深色强调 |
| 900 | `#003154` | `#00433F` | 深色文字或高强调图形 |

亮色 500 阶保持品牌识别。不要默认将白色小字放在蓝 500 或青 500 上；主按钮使用蓝 600，白字对比度为 4.56:1。青色主要承担辅助强调；用于浅底图表时使用青 700 或更深阶。

### 业务状态映射

| 语意 | OMS 状态示例 |
|---|---|
| 中性 | 草稿、未开始、已取消、未知 |
| 警告 | 待确认、临近截止、等待外部处理 |
| 处理中 | 进行中、同步中、处理中 |
| 成功 | 已完成、已通过、操作成功 |
| 错误 / 危险 | 失败、已拒绝、已逾期、不可恢复错误 |
| 信息 | 说明性提示、辅助说明、一般通知 |

状态映射必须与产品状态文案一致。若某状态在业务上存在歧义，先明确语义再选择颜色；不要让同一种颜色在不同模块代表相反含义。

## 5. 组件与可读性规则

- **提示反馈：** 成功、警告、错误、信息提示分别使用对应的文字色、浅背景和边框。危险操作使用错误色；普通主操作继续使用品牌蓝。
- **实心按钮：** 白色文本配表中的“白字实心操作底色”。主按钮使用蓝 600 `#0077D6`；不能将亮蓝 500 或青 500 直接配白色小字。
- **交互态：** 悬停和按下使用语意表中的深色阶。键盘焦点使用蓝色 `#0077D6` 的 2px 外框，并留出可见间距；焦点不通过状态色表达。
- **禁用态：** 使用中性前景与 `#EAF0F5` 背景，不保留成功/错误状态色。禁用本身要有可理解的原因或可恢复路径。
- **图表：** 状态图表使用对应语意色；普通分类图表使用独立序列色，不暗示成功/失败。浅底的蓝青图形应使用蓝 600、青 700 或更深阶，并同时提供标签、图例或数据值。
- **边框：** 浅色语意边框用于辅助分组，不能单独承担控件边界或状态识别；关键状态还须依靠文字、图标或有足够对比的图形表达。
- **颜色之外的线索：** 状态不能只靠颜色表达。提供明确文案，并视组件补充图标、形状、图例或数值。
- **圆角与表面：** 遵循参考图的 4px 圆角，使用浅冷画布和白卡片；避免大面积渐变和重阴影。

### 对比度门槛

- 普通文本与背景至少 `4.5:1`；大号文本至少 `3:1`。
- 识别控件或状态所必需的关键非文本信息至少 `3:1`，例如焦点环、重要图形和必要边界。
- 对比度是颜色组合要求；颜色本身不代表通过。逐一检查组件真实前景、背景、悬停和按下组合，计算值不得四舍五入后判定通过。
- 禁用控件虽有 WCAG 例外，本规范仍优先使用清楚可读的中性颜色。

参考：[W3C WCAG 2.2，1.4.3 Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)；[1.4.11 Non-text Contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。

## 6. 主题范围与配套预览

当前规范定义浅色主题。深色主题须单独建立表面、文字、边界及语意色 token，并重新核验对比度，不可直接反转本表颜色。
