# 有单 OMS 响应式布局规范

> 状态：已定稿　|　适用范围：有单 OMS Web 管理后台　|　生效日期：2026-10-05

## 快速规则

- 以桌面后台为主要工作形态，窄屏优先保持导航可达、任务可完成和数据可读。
- 全系统页面沿用全局顶栏、左侧菜单和右侧工作区；首页在工作区展示仪表盘。参考图没有可可靠读取的响应式断点或容器尺寸。
- 下列断点和列数是本产品的实施基线，按可用内容宽度切换；不得把预览图的画布尺寸当成固定页面尺寸。
- 表格和日历在窄屏优先提供横向查看、筛选或独立详情，避免强行压缩信息。

## 1. 断点基线

| 视口宽度 | 布局策略 |
|---|---|
| `≥ 1440px` | 宽桌面；导航与工作区并列；指标和图表可使用多列 |
| `1200–1439px` | 常规桌面；减少次要留白，保持主要内容完整 |
| `768–1199px` | 窄桌面/平板横屏；可折叠侧栏，卡片减少列数 |
| `< 768px` | 窄屏；导航转为抽屉或移动菜单，页面内容单列优先 |
| `< 360px` | 小屏补充策略；摘要卡改为单列，顶栏次要操作收纳 |

断点用于实现起点，布局应由内容是否拥挤决定。页面不得为匹配某一设备而固定宽度；必要时在实际页面评估后调整，但应更新本规范或记录组件级例外。

## 2. 导航与页面框架

- 桌面端固定保留全局顶栏、左侧菜单和主工作区；顶栏提供一级模块入口及全局操作，左侧菜单显示当前模块/项目的页面导航。
- 首页仪表盘在宽屏按“顶部摘要指标—中段主要图表与快捷操作—下段公告、辅助统计与任务列表”组织；缩窄时保持该阅读顺序。
- 1200px 以下允许侧栏收窄或折叠，仍要保留展开入口、当前页面名称和键盘可达性。
- 768px 以下优先使用抽屉/菜单承载次级导航；主内容不与固定侧栏争抢宽度。
- 顶栏操作按优先级保留；低频项目移入菜单，不能隐藏登录状态、当前组织或退出入口。
- 页面标题、主要操作和筛选区在各视口保持一致阅读顺序。

## 3. 栅格与内容

- 指标卡、快捷入口等重复内容按可用宽度从多列降为两列或单列，顺序与重要性保持稳定。
- 图表并排仅限标题、图例和标签仍清晰可读的宽度；否则改为上下排列。
- 卡片保持内容自然高度，避免固定高度裁切文字、错误提示或操作按钮。
- 页面主要内容与卡片边缘沿统一栅格对齐；间距值遵循布局与间距规范。
- 长标题和字段允许换行；不得通过缩小字体解决溢出。
- 360px 以下优先单列呈现摘要卡，将次要顶栏操作收纳到菜单中；保留主要操作入口。

## 4. 表格、日历与复杂工作区

- 桌面端保留表格主要列和行操作；窄屏按业务优先级隐藏次要列，并提供行详情查看。
- 若列不能安全隐藏，使用横向滚动并让首要识别列保持可见；必须让用户知道还有横向内容。
- 筛选、分页和主要操作在窄屏保持可触达；避免把唯一操作放在横向滚动区域末端。
- 日历窄屏可切换日/周视图或列表视图；保留日期导航和新建任务入口。
- 多步骤选择面板在窄屏使用全屏或近全屏呈现；步骤、返回和提交操作持续可见。

## 5. 可操作性与验证

- 点击目标至少 40×40 CSS px；相邻操作保留清楚间隔。
- 键盘焦点、校验消息和状态反馈不得因断点切换消失或被遮挡。
- 在 320px CSS 宽度至宽桌面范围验证无页面级横向溢出；表格等明确可滚动区域除外。
- 在 200% 页面缩放下检查主要导航、表单、弹层和按钮仍可达且不被固定高度裁切。
- 测试真实内容长度，包括长中文名称、多列数据、空数据、错误信息和较长任务标题。
