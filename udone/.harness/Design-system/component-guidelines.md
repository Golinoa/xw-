# 有单 OMS 组件规范

> 状态：已定稿　|　适用范围：有单 OMS Web 管理后台　|　生效日期：2026-10-05

## 快速规则

- 基础组件使用项目现有 Ant Design Vue 4；优先组合库组件，不重复造基础控件。
- 组件颜色、字号、间距、圆角分别遵循色彩、字体和布局规范，由全局主题统一映射。
- 同一操作区域只设置一个主操作；状态必须清晰表达加载、禁用、成功、警告和错误。
- 新建共享封装前先确认复用场景；业务规则留在业务组件，视觉适配留在共享组件或主题层。

## 1. 组件基础

当前依赖为 `ant-design-vue` 4.2.6，应用入口全局注册。基础选择如下：

| 场景 | 优先组件 | 规则 |
|---|---|---|
| 页面骨架与导航 | Layout、Menu、Breadcrumb、Tabs | 登录后页面统一采用全局 Header、左侧 Sider/Menu 和右侧 Content；当前项有文字/位置提示，不只依赖颜色 |
| 表单与选择 | Form、FormItem、Input、Select、DatePicker | 使用可见标签、就近校验、清晰必填提示；占位文本不替代标签 |
| 操作 | Button、Dropdown | 按钮语义表达操作类型；每个区域仅一个主要按钮 |
| 分区与内容 | Card、Collapse、Descriptions | 仅在形成独立信息分组时使用容器，避免卡片套卡片 |
| 状态反馈 | Alert、Message、Notification、Modal | 持续页面问题用 Alert；短暂结果用 Message；重要异步提醒用 Notification；需决策时用 Modal |
| 数据展示 | Table、Pagination、Statistic、Progress | 显式处理加载、空数据和失败；金额/数量等数据对齐并保留单位 |
| 侧向任务 | Drawer | 用于保留当前页面上下文的编辑或查看流程 |

AI 对话组件不属于当前基础组件范围。开始智能体功能时，再独立评估 `ant-design-x-vue` 并定义对话交互规范。

首页在上述统一框架的主工作区中采用项目管理仪表盘布局；模块入口仍由全局顶栏和左侧菜单承载，不在首页重复构造第二套导航。

## 2. 操作与状态

### 按钮

- **Primary：** 当前区域最重要的提交或继续操作，每个区域最多一个。
- **Default：** 次级或并列操作。
- **Text / Link：** 局部轻量操作，不用于需要明确提交反馈的主流程。
- **Danger：** 删除、撤销等破坏性操作；执行前提供明确对象和后果，必要时二次确认。
- 请求提交后显示 Loading 并防止重复提交；不可用操作显示 Disabled，避免用隐藏代替权限或状态反馈。

### 表单

- 使用 Form / FormItem 组织标签、控件和校验信息。必填、格式错误和服务端错误均在相关字段附近表达。
- 提交失败时保留用户已输入内容；提交成功、失败或处理中均有可见反馈。
- 表单长流程按任务分组；字段说明放在标签附近，placeholder 仅提供输入示例。

### 反馈

- 反馈颜色遵循色彩规范，并同时给出简洁文案；状态不能只靠颜色或图标表达。
- 同一事件避免 Alert、Message、Notification 重复提示。
- Modal 用于需要用户决定或确认的任务；Drawer 用于在保留页面上下文时编辑/查看。一般信息不使用弹窗打断流程。

## 3. 数据组件

- Table 必须定义加载、空结果、请求失败和分页状态；筛选条件改变后重置到有效页码。
- 表格列标题清楚、行操作聚合；数值列右对齐，必要时与字体规范的等宽数字配合。
- Statistic 用于少量关键指标，不以大数字替代详情表格或图表。
- Progress 需呈现进度数值或状态文案；成功/失败颜色遵循语意色规范。
- 窄屏策略遵循布局规范；不可读时采用横向滚动、列显隐或独立详情视图，不强行压缩列内容。

## 4. 主题与封装

- 在应用根部集中设置 Ant Design Vue 主题，将品牌色、字体、圆角和组件尺寸映射到 Design-system token。
- 尺寸优先沿用库默认值；确需紧凑或宽松呈现时，使用组件公开的尺寸配置并保持同一区域一致，不用局部 CSS 改控件高度。
- 页面不得局部覆写库组件默认色值、字号、间距和圆角。确需例外时，在共享组件中限定范围并记录理由。
- 优先使用库组件配置与公开属性；避免依赖内部 DOM 结构或大量 `:deep()` 覆写。
- 仅当同类 UI 至少有明确跨页面复用，或需要封装有单业务行为时，才创建共享包装组件。包装组件不复制整套基础库。
- 新页面按本规范接入；修改既有页面时顺带移除本次涉及区域的硬编码样式，不要求无关页面一次性重写。

## 5. 可访问性与适配

- 使用组件语义与原生表单关联；按钮、输入框、选择器都要有可理解的名称。
- 所有操作可键盘到达，焦点状态清晰；校验错误关联到对应字段。
- 保留 Ant Design Vue 提供的键盘交互和状态行为，不以视觉覆写移除焦点、禁用或错误提示。
- 窄屏与缩放场景保持操作可达、内容不被固定高度裁切；断点采用布局规范及页面自身的内容约束。
- 图标遵循[图标规范](iconography.md)；图表及空/错状态遵循[图表与数据可视化规范](data-visualization.md)。
- 页面栅格和窄屏调整遵循[响应式布局规范](responsive-layout.md)；交互状态与动效遵循[交互反馈与动效规范](interaction-motion.md)。
