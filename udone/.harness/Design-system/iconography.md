# 有单 OMS 图标规范

> 状态：已定稿　|　适用范围：有单 OMS Web 管理后台　|　生效日期：2026-10-05

## 快速规则

- 使用简洁、清晰的线性图标；常规图标以深色描边呈现，选中、强调和品牌操作使用品牌蓝。
- 常用尺寸为 16、20、24px；同一导航或操作组保持尺寸、笔画和对齐一致。
- 图标辅助文字，不单独承担导航、状态或操作含义；纯图标按钮必须有可访问名称。
- 优先复用项目已安装的图标实现；需要新增时优先评估与 Ant Design Vue 配套的按需图标包，不为少量图标引入整套 UI 库。

## 1. 视觉规则

- 参考界面中的功能图标以简练线条为主，图形边界清楚，避免拟物、高光、复杂渐变和多色装饰。
- 默认采用描边图标，同一页面不混用明显不同的线性、面性、手绘或拟物风格。
- 线条端点和转角保持一致；24px 图标建议使用约 2px 描边，缩小尺寸时优先使用图标库对应规格，不通过非等比缩放改变笔画。
- 普通图标使用中性色；当前项和主要动作使用品牌蓝；成功、警告、错误状态图标使用对应语意色，并同时显示状态文案。
- 禁止用纯色图标代替控件边界或文本标签。装饰图标不得干扰信息阅读。

## 2. 尺寸与位置

| 尺寸 | 用途 | 对齐方式 |
|---|---|---|
| 16px | 表格行操作、辅助说明、紧凑按钮 | 与 14px 文本基线居中 |
| 20px | 菜单项、常规按钮、输入框前缀 | 与相邻文本垂直居中 |
| 24px | 卡片入口、空状态、强调操作 | 与标题或主体内容组成独立视觉组 |

- 图标点击目标按控件规范设置；可视图形尺寸不等于点击区域尺寸。
- 同一列表或导航中的图标占位宽度固定，避免标签因图形宽度差异错位。
- 图标与文字间距使用布局间距 token；同类按钮与菜单项保持一致。
- 不拉伸、旋转或裁切图标来适配容器；需要不同朝向时使用明确的方向图标。

## 3. 语义与使用

- 新建、搜索、筛选、日历、通知、文档、成员、统计等图标应选择直观且全产品一致的语义。
- 同一图标在不同模块不得表示相反操作；删除、关闭、返回、取消等相近动作应使用可区分图形并配文字或提示。
- 状态图标与色彩规范一致，且同时有明确文案、标签或可访问名称。
- 仅图标按钮用于空间受限且用户已熟悉的重复操作；重要、危险或低频操作优先显示文字。
- 图标不得承载品牌标识以外的文字；不把表情符号作为正式界面图标。

## 4. 可访问性

- 纯图标按钮提供可访问名称，Tooltip 不能作为唯一名称来源。
- 装饰性图标从辅助技术阅读顺序中隐藏；有语义的图标提供可读标签。
- 图标颜色与相邻背景满足非文本对比度要求；不能只以颜色区别状态。
- 保留键盘焦点、禁用和交互状态，不通过图标 CSS 隐去焦点反馈。

## 5. 组件库落地

- 优先复用项目已安装的图标实现。当前 Web 依赖未声明图标包；新增图标时可评估 `@ant-design/icons-vue` 并按需导入，检查构建体积后再引入。
- 在业务页面集中按语义选择图标，避免直接复制 SVG 片段形成多个不一致版本。
- 若确需自绘图标，使用可缩放 SVG，声明 `viewBox`，保持单色描边，并说明其语义和适用范围。
- 组件图标颜色继承 CSS `currentColor`；状态色由语意 token 控制。
