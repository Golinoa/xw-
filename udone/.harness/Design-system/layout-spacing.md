# 有单 OMS 布局与间距规范

> 状态：已定稿　|　适用范围：有单 OMS Web 管理后台　|　生效日期：2026-10-05
>
## 快速规则

- 参考图明确提出 4px 圆角，并把间距按密集、常规、宽松、疏朗分组。
- 登录后的系统页面统一采用“全局顶栏 + 左侧菜单 + 右侧主工作区”框架；首页主工作区采用项目管理仪表盘布局。
- 间距统一使用 CSS px；保留可辨识的 `102` 刻度。
- 图中的项目管理 UI 为缩小后的展示图，没有可可靠反推的精确容器宽度、边栏宽度或断点；以下只记录可见层级，不推算像素尺寸。

## 1. 参考图明确标注

### 1.1 间距分组与 token

截图的横向间距刻度显示：

| 分组 | 数值（CSS px） | 密度 |
|---|---|---|
| `≤ 10` | 2、4、6、8、10 | 紧凑 |
| `10 ~ 32` | 12、16、20、24、28 | 常规 |
| `32 ~ 64` | 32、40、48、56、64 | 宽松 |
| `≥ 72` | 80、96、102、128、… | 疏朗 |

纵向示例刻度为 4、8、12、16、20、36、40、56；纵向优先复用这些值，必要时可选其他值。

### 1.2 圆角

普通矩形容器统一使用 **4px** 圆角。圆形、胶囊等形态由组件规范定义；页面不得自行增加圆角值。

## 2. 产品界面可见的布局模式

以下为缩小展示图中的**可见模式**，不是可以按截图像素照搬的尺寸规范：

- **系统框架：** 全局顶栏承载品牌、一级模块导航和全局操作；左侧菜单承载当前模块的页面/项目导航；右侧作为主工作区。
- **首页仪表盘：** 顶部为摘要指标卡；中段并排放置任务状态、近期任务等主要分析图表和快捷操作；下段放公告/通知、辅助统计和任务列表。信息按“概览—分析—待办明细”顺序展开。
- **日历：** 左侧保留项目/任务筛选区，右侧以月历或周历作为主内容；视图切换和新建操作放在日历上方。
- **任务处理：** 主页面负责展示任务与上下文；选择任务、选择成员等步骤采用层叠面板或弹窗，完成当前步骤后再进入下一步。
- **信息层级：** 页面标题和主要操作先于筛选条件；筛选与工作内容分区；表格、日历等高密度工作面板拥有清晰、连续的主区域。
- **网格对齐：** 同一行卡片边缘对齐，重复模块保持一致间距；页面标题、卡片和表格沿同一内容边界对齐。

## 3. 间距 token

以下数值作为正式 CSS 间距 token。分组表示密度层级，不要求每个组件使用全部刻度，也不允许任意插值。

| Token | 值 | 间距层级 |
|---|---:|---|
| `space-2` | 2px | 横向：紧凑 |
| `space-4` | 4px | 横向、纵向示例 |
| `space-6` | 6px | 横向：紧凑 |
| `space-8` | 8px | 横向、纵向示例 |
| `space-10` | 10px | 横向：紧凑 |
| `space-12` | 12px | 横向、纵向示例 |
| `space-16` | 16px | 横向、纵向示例 |
| `space-20` | 20px | 横向、纵向示例 |
| `space-24` | 24px | 横向：常规 |
| `space-28` | 28px | 横向：常规 |
| `space-32` | 32px | 横向：宽松 |
| `space-36` | 36px | 纵向示例 |
| `space-40` | 40px | 横向、纵向示例 |
| `space-48` | 48px | 横向：宽松 |
| `space-56` | 56px | 横向、纵向示例 |
| `space-64` | 64px | 横向：宽松 |
| `space-80` | 80px | 横向：疏朗 |
| `space-96` | 96px | 横向：疏朗 |
| `space-102` | 102px | 横向：疏朗 |
| `space-128` | 128px | 横向：疏朗 |

横向刻度构成完整 token 集；纵向示例复用该集合。组件用途由页面与组件规范确定。

## 4. 布局规则

1. 已确认所有登录后的系统页面采用全局顶栏、左侧菜单和右侧主工作区；全局顶栏与左侧菜单承担不同层级的导航。
2. 首页采用仪表盘：先展示摘要指标，中段展示主要图表和快捷操作，下段展示公告、辅助图表和任务列表。
3. 日历等业务页沿用相同系统框架；左侧菜单负责模块/项目导航，主工作区呈现当前页面的主要日历或任务内容。
4. 任务处理截图使用覆盖主页面的选择面板展示分步操作；参考图没有标出面板尺寸或遮罩规则。
5. 同级模块沿共同边界对齐，重复卡片按网格排列，是参考图中可见的视觉规律。
6. 图中没有给出卡片 padding、页面边距、侧栏宽度、容器最大宽度或响应式断点，不能从缩小截图可靠提取这些值。

## 5. 项目落地规则

### 5.1 间距

- 分别管理容器内边距、同级元素间距和页面分区间距；不将间距刻度用于控件尺寸或字体规格。
- 同组重复元素保持间距一致，由父级布局统一控制，避免留白叠加。
- 刻度与组件的对应关系在组件规范中定义，页面不得自行映射。

### 5.2 页面与响应式

- 顶栏、侧栏、内容宽度、页面边距和断点按实际页面及目标屏幕确定，不套用预览线框尺寸。
- 窄屏调整导航、列数或表格呈现；优先保障内容可读、主要操作可达。

### 5.3 圆角与例外

- 普通容器使用 4px；圆形、胶囊等形态由组件规则定义。
- 偏离规范须在对应页面/组件说明中记录原因与适用范围。
